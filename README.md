# Next Gen Learning Student Dashboard

An interactive dashboard prototype designed for students to track their courses, progress, and learning activities. Built using Next.js, TypeScript, TailwindCSS, and modern UI practices.

## Features
- **Student Progress Overview**: Track course completions and grades.
- **Activity Log**: View daily/weekly learning activities.
- **Interactive UI**: Clean, responsive layout with dark mode support.
- **Bento Grid Layout**: Beautiful modern visualization of student metrics.
